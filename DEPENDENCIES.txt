--------------------------------------------------------------------------------
3.1 Tesseract-OCR Engine (Required for Image & Scanned PDF OCR)
--------------------------------------------------------------------------------
PyTesseract is a Python wrapper that communicates with the native Tesseract binary.
To perform OCR on scanned PDFs and images, Tesseract must be installed on the host OS:

• Windows Installation:
  1. Download installer: https://github.com/UB-Mannheim/tesseract/wiki
  2. Run installer and install to default location:
     C:\Program Files\Tesseract-OCR\tesseract.exe
  3. Add "C:\Program Files\Tesseract-OCR" to Windows System PATH.
  4. Verify in PowerShell/CMD:
     tesseract --version

• Linux (Ubuntu / Debian) Installation:
  sudo apt-get update
  sudo apt-get install -y tesseract-ocr tesseract-ocr-eng libtesseract-dev

• MacOS Installation:
  brew install tesseract
